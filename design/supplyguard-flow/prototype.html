这个工具是做什么的 / WHY AGENT-BASED

01 / 问题

传统 SCA 工具只能匹配已知漏洞数据库。但供应链攻击正在升级：AI 幻觉包、0day、恶意投毒——这些在 CVE 有记录之前就已经在危害项目了。

02 / 解法

SupplyGuard 用 多 Agent 协作 做智能决策：Sentinel 守护边界、Analyst 深度分析、Auditor 综合裁决。不是跑规则，是像安全工程师一样思考，发现"看起来正常但实际可疑"的威胁。

03 / 闭环

每一次 Agent 裁决都被记录在 HMAC-SHA256 审计链 中，不可篡改。六个月后依然可以回放：Agent 看到了什么、为什么判断为风险、您最终如何裁决。
